htmx data grid from a server-rendered table

The server renders a plain task table for four teams; Lattice turns it into an editable, sortable data grid with no mount code, and htmx handles the swaps and the save. A stand-in server answers htmx's requests in your browser, so nothing leaves the page.

Saved by the server

    Try the five steps

    1. Built on load. The task list was a server-rendered table; the grid replaced it on load, with the Task, Owner, Status and Points columns editable.
    2. Edit. Double-click a cell, change it and press Enter. lattice:grid-change is posted with hx-post and the server confirms below the grid.
    3. Sort. Click the Points header to sort. The sort is view state, kept by the grid and saved with the history snapshot.
    4. Swap. Pick a team. hx-get fetches its tasks, the old grid is torn down and a new one is built.
    5. Back. Press the browser Back button. The earlier team and the sort return, with the grid drawn once.
